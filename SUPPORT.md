# Support

ContinuityDB is alpha software maintained in public.

## Choose the right channel

- Use [GitHub Discussions](https://github.com/deva-prakash-j/continuitydb/discussions)
  for installation help, workflow questions, early ideas, and show-and-tell.
- Open a [bug report](https://github.com/deva-prakash-j/continuitydb/issues/new/choose)
  for a reproducible product problem with sanitized diagnostics.
- Open a feature request after the desired behavior and scope are clear.
- Report vulnerabilities through a
  [private security advisory](https://github.com/deva-prakash-j/continuitydb/security/advisories/new).

Never post credentials, private source code, private repository paths, raw
memory records, or employer data. Include the ContinuityDB version, platform,
installation method, connected client, reproduction steps, and expected versus
actual behavior whenever possible.

There is currently no guaranteed response-time SLA. Clear, minimal,
secret-free reproductions are the fastest path to a useful answer.
